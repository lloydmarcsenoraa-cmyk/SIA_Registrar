# RegistrarSys — Design System

## 1. Overview

RegistrarSys follows a clean, professional, and consistent design approach for the SIA College Management System.

This document defines the proposed visual standards for the Registrar module's Figma prototype. The final design must be aligned with the class-wide shared design system.

## 4. Spacing and Layout

Use an 8px spacing system.

- Small spacing: 8px
- Medium spacing: 16px
- Large spacing: 24px
- Section spacing: 32px
- Card border radius: 12px
- Button border radius: 8px

Desktop prototype target: 1440px width.

Mobile prototype target: 390px width.

## 5. Navigation

### Desktop

Use a left sidebar with the following navigation items:

- Dashboard
- Students
- Programs
- Courses
- Enrollments
- Academic Records

### Mobile

Use a responsive navigation menu that provides access to the same features.

## 6. Components
